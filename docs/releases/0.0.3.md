# BetterReports 0.0.3

For OpenSearch and OpenSearch Dashboards **3.8.0**.

- Align the secondary sidebar title and navigation items.
- Replace the expandable JSON filter input with the native Discover query bar and multiple-filter builder, including field/operator/value selection, custom labels, exclusion, disabling, deletion, and Query DSL editing.
- Use the report's saved index-pattern field definitions for the builder; upstream field changes still require Refresh sources. Existing report queries and filters remain available.
- Align the Scheduled delivery timezone dropdown with adjacent controls, and keep BetterReports form styles from overriding native Dashboards controls.

## Upgrade

Stop the services, remove the old plugins, install both ZIPs from this release, and restart OpenSearch followed by Dashboards. Replace plugins on every applicable node/instance. Existing reports, filters, schedules, and authorizations are retained; do not delete the BetterReports indices. No configuration or permission changes are needed when upgrading from 0.0.2. Hard-refresh the browser or clear its cached site assets.

Upgrading from 0.0.1 also requires the Notifications migration described in [Deployment](https://github.com/basht0p/BetterReports/blob/v0.0.3/docs/DEPLOYMENT.md).

## Validation

Existing unit tests, TypeScript checks, and exact 3.8.0 source contracts, plus browser checks against the official 3.8.0 Dashboards image for native filters and the corrected layouts. This UI release does not repeat the 0.0.2 100-schedule load test.
