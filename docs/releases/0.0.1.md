# BetterReports 0.0.1

Initial release for self-hosted **OpenSearch and OpenSearch Dashboards 3.8.0 exactly**. Install both companion and Dashboards plugins. The ZIP filenames include the required platform version; both plugin manifests identify this release as `0.0.1`.

## Features

- Import existing dashboards and supported saved visualizations into section-based reports.
- Generate native PDF text, vector charts, and paginated tables on 8.5 × 11 inch US Letter pages.
- Preview the actual PDF in the browser and download identical bytes.
- Customize branding, repeating headers/footers, logos, and page numbering.
- Schedule SMTP PDF delivery with timezone-aware recurrence and shared job coordination across Dashboards instances.
- Authorize scheduling through the companion plugin without per-user REST impersonation allowlists. Map SAML backend groups to the reporting role.
- Manage indefinite scheduling authorizations with owner and tenant-manager revocation. One-off run permissions are cleaned up separately.

## Installation

Download the two ZIPs and their `.sha256` files from this release. Install the companion on every OpenSearch node and the Dashboards plugin on every Dashboards instance. Follow [Deployment](../DEPLOYMENT.md) for Security system-index protection, role mappings, worker credentials, and SMTP configuration.

Scheduling authorizations last until explicitly revoked. SAML logout, token expiry, account disablement, or group removal does not revoke an existing grant. Current definitions of captured OpenSearch roles continue to govern data queries. Report edits and source refresh require reauthorization.

## Validation and scope

The implementation passed 25 automated tests and live exact-3.8.0 checks covering rendered PDFs, source freshness, tenant/owner isolation, DLS/FLS, signed SAML session expiry, restart persistence, revocation, two-instance execution, and scheduled STARTTLS delivery. The companion architecture also completed a 100-schedule fixture with 100 distinct emails; that benchmark preceded the final one-off permission cleanup refinement, which was subsequently integration-tested.

This is the initial release. Test representative dashboards and your own identity-provider/SMTP configuration before production rollout. Workspaces, managed-service installation, advanced visualization types, alternate paper sizes, and non-SMTP delivery are outside v1 scope.
