# BetterReports 3.10.0

Compatibility and security release for OpenSearch and OpenSearch Dashboards 3.10.0.

- Supports OpenSearch and OpenSearch Dashboards 3.10.0, with Security, Notifications, and Notifications Core 3.10.0.0. No BetterReports features or behavior changed; the plugin code is the same as 3.9.0.1 apart from the platform version.
- **Picks up the platform's security fixes.** The 3.9.0 base images are affected by issues that 3.10.0 fixes, so the container images and any 3.9.0 deployment should move to 3.10.0:
  - Node.js in Dashboards goes from 22.23.0 to 22.23.4, which fixes the actively exploited Brotli decoder out-of-bounds write (CVE-2026-111497, in CISA's Known Exploited Vulnerabilities catalog) and the July and October 2026 Node.js security releases.
  - `@hapi/content` goes to 6.0.3, fixing a denial of service on multipart upload routes (CVE-2026-115728).
  - OpenSearch bundles JDK 25.0.5, with the October 2026 Java security fixes.
  - None of these were in BetterReports code. The plugin's own dependencies had no known vulnerabilities before or after this release.
- **Still open in the platform:** Dashboards 3.10.0 bundles Node.js 22.23.4, which lacks the 2026-11-11 Node.js security release (fixed in 22.23.5). CVE-2026-123864 affects Dashboards only when it serves HTTPS itself. Terminate TLS at a reverse proxy in front of Dashboards until OpenSearch ships a newer Node.js. See [Deployment](../DEPLOYMENT.md#upgrading-to-3100).
- The container images are now built from the official 3.10.0 images pinned by digest, so a re-pushed upstream tag cannot change what a BetterReports release contains: `ghcr.io/basht0p/betterreports-opensearch:3.10.0` and `ghcr.io/basht0p/betterreports-dashboards:3.10.0`.
- No changes to report storage, grants, roles, or configuration keys. Existing reports, schedules, and authorizations carry over unchanged.

OpenSearch 3.9.0 and Dashboards 3.9.0 are not supported by this release. To upgrade, remove both 3.9.0.x plugins, upgrade the platform to 3.10.0, then install both 3.10.0 plugins together and hard-refresh the browser. See [Deployment](../DEPLOYMENT.md#upgrading-to-3100).
