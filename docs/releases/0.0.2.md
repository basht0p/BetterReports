# BetterReports 0.0.2

For OpenSearch and OpenSearch Dashboards **3.8.0 exactly**. Install both plugin ZIPs and verify the accompanying SHA-256 files.

- OpenSearch-style secondary sidebar replaces the top tabs.
- Scheduled PDFs use existing Notifications email senders (SMTP or SES) and email recipient groups.
- Reporting periods use the standard Dashboards relative/absolute time picker; report and schedule timezones use searchable IANA dropdowns.
- Report sections have mouse and keyboard drag handles.
- Reports navigation returns to Your reports; the editor includes Cancel.
- Deletions use in-page confirmation modals.
- Removed the preview placeholder tagline.

## Upgrade

Update both plugins and the roles in `companion/roles.json`. Remove `better_reports.smtp` from Dashboards configuration. Existing schedules pause until an owner selects Notifications sender/groups and enables the schedule again. Reports, authorizations, and stored PDFs remain available.

Notifications must be installed on OpenSearch. Configure sender credentials and TLS in Notifications. BetterReports creates a temporary email channel per delivery and cleans it up afterward. Unknown dispatch results require deliberate resend after reviewing delivery. See [Deployment](https://github.com/basht0p/BetterReports/blob/v0.0.2/docs/DEPLOYMENT.md) for permissions, migration, and cleanup details.

After upgrading, perform a browser hard refresh (or clear cached site assets) so Dashboards loads the new plugin JavaScript and styles.
