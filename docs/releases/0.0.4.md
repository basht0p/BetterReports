# BetterReports 0.0.4 development build

- Adds rendered PDF support for Gauge, Goal, Heat Map, Horizontal Bar, Coordinate Map, Region Map, and Tag Cloud. Area, Data Table, Line, Metric, Pie, and Vertical Bar remain supported.
- Imports a constrained Maps application saved object containing one fixed-precision geohash cluster layer, and basic single-series Timeline expressions. Unsupported layers, expressions, and visualization settings fail with a visible reason.
- Uses vector map outlines and chart geometry, with selectable table and tag-cloud text. The existing preview, scheduling, grants, and branding pipeline is unchanged.

Validation: 34 automated tests, TypeScript typecheck, and 15 platform source contracts against OpenSearch Dashboards 3.8.0. The official 3.8.0 Docker images installed both ZIPs and passed live import/query/PDF checks for the new aggregation visualizations and basic Timeline, plus the existing authorization and scheduled-email suite. Standalone Maps saved objects still need a live run with the optional Maps plugin installed before a public release.
