# BetterReports 0.0.4

- Adds rendered PDF support for Gauge, Goal, Heat Map, Horizontal Bar, Coordinate Map, Region Map, and Tag Cloud. Area, Data Table, Line, Metric, Pie, and Vertical Bar remain supported.
- Keeps the separate Maps application and Timeline expression visualizations unsupported. Coordinate Map and Region Map refer to the aggregation-based visualization types.
- Uses vector map outlines and chart geometry, with selectable table and tag-cloud text. The existing preview, scheduling, grants, and branding pipeline is unchanged.

Validation: automated tests, TypeScript typecheck, 15 platform source contracts, and live import/query/PDF checks for the new aggregation visualizations on the official OpenSearch/Dashboards 3.8.0 images, plus the existing authorization and scheduled-email suite.
