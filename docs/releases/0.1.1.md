# BetterReports 0.1.1

- Keeps report-card logos inside a bounded area, preserving aspect ratio for large, wide, and tall images.
- Renames Open report to Open and matches its styling to Generate and Clone Report.
- Aligns the BetterReports sidebar heading with its submenu labels.
- Simplifies the builder to Filters only, removing the query editor. Native Add filter remains available in both Dashboards header modes. Existing saved queries remain visible as removable saved-filter chips so report results do not silently change.

Compatible with OpenSearch and OpenSearch Dashboards 3.8.0. For an existing 0.1.0 installation, replace the Dashboards plugin using the existing upgrade procedure, then hard-refresh your browser to load the updated styles. The companion plugin code is unchanged; its 0.1.1 ZIP is included for new installations or matching component versions. No role, configuration, or storage changes are required when upgrading from 0.1.0. See [Deployment](../DEPLOYMENT.md).
