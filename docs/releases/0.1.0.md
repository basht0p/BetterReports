# BetterReports 0.1.0

- Adds a per-section Hide legend checkbox and lays out legends separately from chart graphics so long labels cannot overlap the chart.
- Uses current, authorized index-pattern fields in the native Dashboards filter controls, including keyword fields, operators, and custom labels.
- Shares report definitions within a tenant, with tenant write permission required to edit, delete, or clone. Global-tenant administrators can see all-tenant report metadata; report actions require selecting the report's tenant.
- Keeps generated PDFs, run history, and schedules private. Each interactive run uses the generating user's permissions. Cloning copies a report definition and branding without copying authorizations, schedules, or PDFs.
- Adds organization names, optional logos, and branding-color accents to report tiles.

Install both 0.1.0 plugin ZIPs and update the worker role from `companion/roles.json`. The new worker-only grant invalidation action retires an old authorization when a shared report is changed. Report edits and source refresh pause linked schedules and require new scheduling authorization. Existing stored reports become visible to other users with access to the same tenant; existing PDFs remain private. See [Deployment](../DEPLOYMENT.md) for the upgrade procedure.
